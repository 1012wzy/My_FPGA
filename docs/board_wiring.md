# 接线表与控制参数

适用 MLK-H3 VER20240320、CZ08 XC7Z100FFG900-2、FEP-GPIO-CEPX3 3V3 扩展板。以下 J2/J3/J4 均指扩展板接口；按 PCB 的 1 脚丝印识别针号，不按照片左右推断。VADJ2 为 3.3 V。原理图摘图及引脚映射见 [硬件资料索引](reference/README.md)，阵列安装参考见 [装配图](reference/mic_array_assembly.png)。

## 麦克风与云台：CEP2/J3

| J3 针号 | 接到 |
|---|---|
| 1 | 阵列 VIN，已采用并实测的 3.3 V 供电 |
| 2 | 阵列 GND、公共地 |
| 3 / 4 | MIC_CK / MIC_WS |
| 5 / 6 / 9 / 10 | MIC_D0 / MIC_D1 / MIC_D2 / MIC_D3 |
| 11 | 左右舵机 PWM 信号 |
| 12 | 俯仰舵机 PWM 信号 |

四条 I²S 数据线接收七路麦克风。两颗 TBSK15 舵机使用独立 5 V 电源，负极共地；不能通过 CEP 信号针给舵机供电。左右范围 500～2500 μs，中位 1500 μs；俯仰范围 1350～2500 μs，中位 1600 μs。两轴方向系数均为 +1。模式 2 持续输出左右中位指令，装配时使阵列面向车头。

## OV5640：CEP1/J2

| 摄像头端子 | J2 针号 | FPGA 球脚或供电去向 |
|---|---|---|
| 3V3 | 不接 J2 | 独立稳压模块 3.3 V |
| GND | 不接 J2 | 稳压模块 GND（与主板共地） |
| SDA / SCL | 3 / 4 | AH28 / AH29 |
| VSYNC / HREF | 5 / 6 | AJ28 / AJ29 |
| XCLK / PCLK | 7 / 8 | AE28 / AF28 |
| D0 / D4 | 9 / 10 | AJ30 / AK30 |
| D7 / D6 | 11 / 12 | AJ26 / AK26 |
| D5 / D3 | 13 / 14 | AE25 / AF25 |
| D2 / D1 | 15 / 16 | AG26 / AG27 |
| RST | 不接 J2 | 摄像头同源稳压 3.3 V |
| PWDN | 不接 J2 | 稳压模块 GND |

HDMI 使用主板 HDMI OUT。模式 2 可以不接显示屏，当前实现仍保留视频链路。

## TB6612：CEP3/J4

| TB6612 端子 | J4 针号 | FPGA 球脚或供电去向 |
|---|---:|---|
| VCC | 不接 J4 | 独立稳压模块 3.3 V |
| GND | 不接 J4 | 稳压模块 GND（与主板共地） |
| PWMA | 3 | Y28 |
| STBY | 4 | AA29 |
| AIN1 | 5 | AB27 |
| AIN2 | 9 | AA27 |
| PWMB | 11 | Y26 |
| BIN1 | 13 | Y30 |
| BIN2 | 15 | AB29 |
| VM | 不接 CEP | 电机稳压电源 +12 V |
| AO1 / AO2 | 不接 CEP | 左轮电机两根动力线 |
| BO1 / BO2 | 不接 CEP | 右轮电机两根动力线 |

电机为 MG513XP28_12V；左右按车头前进方向确定。STBY 由 PL 控制，程序启动阶段保持电机驱动关闭；不要将 STBY 直接短接 VCC。未列出的 J4 针脚不接。电机编码器未使用，不能把编码器线当动力线。

主板、阵列、摄像头、TB6612 逻辑与独立电源负极共地；电机电流经 TB6612 直接回到电机电源，不能经子卡细地线回流。TB6612 的 12 V 支路仅接 VM，主板的 12 V 接专用电源入口；不能将 12 V 接到 VCC 或 CEP 信号针。电源持续电流和电机堵转电流仍须按实物规格核实。

先断电接线、架空车轮验证极性。某轮方向相反时，断 VM 后交换该轮的两根动力线，或修改 car.h 的方向常量后重编，避免两处同时反转。驱动撤销为高阻待机，不是机械立即刹停；运行区域应便于人工断开 VM。

## 参数位置

`soc_sdk/src/car.h` 定义基础档 64/256、差速 38/256、10°死区、50°满转、1200 ms 失声保持与 500 ms 旧采样拒绝。更改参数后必须重新编译 PS；需要固化时同步生成 BOOT.BIN。源码与引脚约束为最终工程依据，接线修改应同步验证。

# 协作与报告证据材料

设计报告作为独立文档提交。本目录提供与报告配套的大模型协作记录及验证证据索引。

- [collaboration_record.md](collaboration_record.md)：研发提示词摘录、处理与纠错摘要；不是完整对话原文。
- [evidence/README.md](evidence/README.md)：报告引用的证据及用途。原始记录位于 `soc_prj/reports`，索引记录对应的来源路径和 SHA-256。
- [../skill/README.md](../skill/README.md)：复用工作流、适用范围、使用方法、验证依据与失效条件。
- 报告与工程包的逐项分工见 [根目录 README](../README.md)。

作品信息：团队编号 45441，拉普拉斯变换队，基于 Zynq 的灾害救援系统，AMD 自主选题高级组。

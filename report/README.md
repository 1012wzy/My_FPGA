# 报告配套材料

设计报告及海报作为独立文件提交，本目录不保留其副本。

- [协作记录](collaboration_record.md)：案例索引、采用依据与边界。
- [原始会话摘录](collaboration_cases.md)及[结构化文字](collaboration_cases.json)：真实提示、回答和纠错链。
- [优化与验证](optimization.md)：500/1200 ms参数对照、共享硬件的资源说明及可复现命令。
- [证据索引](evidence/README.md)：历史原始记录路径和哈希。
- [声学实测规范](measurement_protocol.md)：尚待开展的规范测量方法。
- [完整复现](../docs/reproduce.md)及[可复用工作流](../skill/README.md)。

新增续行对照是主机测试，历史CSV是当时板上观测；二者都不能冒充最终整车定位精度。各证据的试验类型和版本应随报告一起说明。

# 续行策略优化与参考对照

## 对照方法
主机试验直接编译提交源码`car.c`。脚本仅在临时目录复制`car.h`并分别将`CAR_LOSS_MS`设为500和1200，其他参数一致；生产文件不改写。两组均采用30°可信方位、60 ms样本年龄、每900 ms一次新观测、20 ms轮询，持续10.8 s，共540个采样点。参考授权定义为“距最后可信观测的时间小于本组保持期限”。

| 指标 | 500 ms参数基线 | 1200 ms提交配置 |
|---|---:|---:|
| 授权采样点/总采样点 | 300/540 | 540/540 |
| 授权采样点占比 | 55.56% | 100.00% |
| 试验区间内授权撤销次数 | 12 | 0 |
| 授权建立次数（含首次） | 12 | 1 |
| 逐点参考不一致数 | 0 | 0 |
| 控制状态Car大小 | 72字节 | 72字节 |
| 失声期限前1 ms仍授权/到期限撤销 | 通过 | 通过 |
| 500 ms旧样本拒绝 | 通过 | 通过 |

“授权”指软件运动许可，不等同于实测车速或位移。此为确定性参数消融，既不复现所有旧版修改，也不代表声学检出率或真实车辆连续行驶率。

## 资源与时序
该对照只改变PS控制常量，两组共享同一PL实现，因此资源对照均为LUT 4406、寄存器5552、BRAM Tile 529、DSP48E1 6；WNS 0.700 ns、WHS 0.056 ns、TNS 0。对应`utilization.rpt`和`timing.rpt`。这是相同硬件下的参数对照，不是两次独立布局布线测量。当前三帧缓存使用BRAM的70.07%，是主要片上资源开销。

## 实物证据与边界
板上记录保留在`soc_prj/reports`：声音输入、图像计数及模式状态属于实测；本节新增的逐点授权数据属于主机测试。现有资料未形成统一的已知角度、声压、距离与环境条件下的定位误差统计。1°为搜索步长，不作精度承诺。新增长保持也意味着真实失声时最长续行更久，系统保留500 ms采样时效拒绝、采集故障和PL命令超时保护。

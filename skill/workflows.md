# 四类可复用工作流

## 一 采集分层排查
适用：DMA完成但没有声音、通道幅度异常、同步错误。输入：原理图、I/O约束、I²S参数、原始七路样本及帧号。
1. 断电核对供电、共地及信号端名，不能按照片左右猜针号。
2. 核对BCLK/WS、时隙位宽、有效位宽、左右时隙分配和符号扩展。
3. 检查连续帧号，再查看每通道非零样本、最小最大值和RMS。
4. 先用已知单音确认接收，再用宽带人声验证应用层声源判决。
5. 把失败定位到供电、协议、搬运、算法之一；禁止用调大增益掩盖全零输入。
来源：本项目出现帧号正常但七路全零，实际接线修正后恢复。边界：通过帧号检查不能证明通道顺序、相位或幅度准确。
可复用提示词：请依据附件原理图、约束和原始样本区分供电、I²S时序、DMA与算法故障；对每个判断列出证据和下一项最小验证，不擅自修改未确认引脚。

## 二 异步视频帧所有权
适用：传感器时钟与显示时钟不一致的整帧缓存。输入：每帧尺寸、像素格式、写入边界、显示换帧点和CDC协议。
1. 明确显示、排队、采集三个角色，禁止采集覆盖显示或待接收帧。
2. 统计行数、每行像素、总像素及奇数字节，仅允许完整帧排队。
3. 跨域传递帧编号时使用握手，确认对方消费后才释放所有权。
4. 显示端在帧边界换帧；忙时明确选择丢候选帧或背压。
5. 仿真不同相位和速率、复位中断、短帧、长帧、交接忙等情况。
来源：黑底红条与卡帧排查后采用三帧交接，回归见工程camera相关日志。边界：不能凭缓存逻辑证明传感器曝光、I/O时序或镜头标定正确。
可复用提示词：请列出该帧缓存的所有权不变量，并设计能触发读写同帧、握手丢失和不完整帧显示的反例测试。

## 三 显示保持与运动授权分离
适用：视觉标记、语音事件驱动云台或小车。输入：观测时间、质量、模式、控制周期和停止期限。
1. 区分原始角度、可信新观测、显示保持状态和运动许可。
2. 只有新鲜可信观测可刷新最后有效时间，显示保持不能刷新。
3. 将语音间隙容忍与采样年龄阈值分成两个参数。
4. 测试期限前1 ms、期限时、超过期限、旧样本、时间回绕和模式切换。
5. 把PS命令回放到PL，检查PL心跳和声源租约是否实际撤销使能。
来源：500 ms间隙保持造成启停，改为1200 ms且保留500 ms采样年龄检查。已有900 ms反复间隙、1199/1200 ms边界测试。
边界：延长保持会延后真实失声停车；误判声源仍可能刷新许可，因此不能替代真实背景和电机噪声测试。没有障碍传感器时不用于无人值守接近。
可复用提示词：请保持共同声源检测算法不变，只修正短暂漏检的运动状态；列出哪些事件能续期、哪些不能，并验证旧数据与故障不会延长运动。

## 四 成套构建与冷启动核验
适用：Zynq的bit/XSA/ELF/FSBL/BOOT组合。输入：工具版本、器件、构建清单、启动介质及下载日志。
1. 先验证硬件与软件接口及源文件哈希，禁止混用不同地址表的旧产物。
2. 全量构建后核对资源、时序、测试退出码及明确成功标志。
3. 分别验收JTAG临时运行、启动镜像分区、Flash识别与擦写校验。
4. 固化后断电，再按实际板卡启动模式冷启动，记录没有JTAG时的运行。
来源：Flash初始化失败与旧文件混用的排查；启动分区和应用段核验见 ../report/evidence。
边界：Flash拓扑、引脚和FSBL依赖板卡；不得在未知连接下尝试擦写。镜像生成不代表冷启动已通过。
可复用提示词：请只读检查当前bit、XSA、ELF和BOOT是否来自同一构建；先报告差异与证据，未得到实际校验成功不得声称已经固化。

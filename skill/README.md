# 可复用的嵌入式声学系统验证工作流

本技能包是AMD自主选题所要求的可复用经验文档，适用于Zynq裸机采集、跨时钟视频和声音驱动执行器系统，不是PYNQ专用插件。

## 使用方法
先阅读 workflows.md，选择与当前故障对应的一节。每节提供输入、步骤、验证证据和失效条件。将板卡型号、信号映射及工具路径换成实际值；保留原基线后再改代码。检查结果应保存为原始日志和版本清单。

## 已验证效果与边界
本项目的参考实现位于工程 soc_prj、soc_sdk 与 scripts，证据索引见 ../report/evidence，原始日志保存在 ../soc_prj/reports。车轮续行1200 ms、500 ms旧样本拒绝和命令回放已覆盖主机与RTL测试；这不证明任意麦克风、混响和电机环境都不存在误判。所有图像标记都需要实物安装标定。

## 协作原则
模型用于提出假设、检查源码、设计测试，不能将模型推断当实测。没有板卡时只报告离线验证；Flash识别、擦写和冷启动验收须分开。每次改动附来源、修改范围和回归结果。

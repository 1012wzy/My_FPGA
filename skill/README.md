# 可复用声学嵌入式系统工作流

本技能包适用于Zynq裸机采集、异步视频显示及声音驱动执行器。四类工作流见[使用说明](workflows.md)，可作为提示词流程和结构化排查清单复用，不依赖PYNQ。

| 工作流 | 适用场景与输入 | 来源及验证 | 失效边界 |
|---|---|---|---|
| 采集分层排查 | 帧号正常但样本为零；输入供电、引脚、I²S时序及原始样本 | 真实接线故障；七通道及组帧仿真、板上原始记录 | 连续帧号不能证明通道相位和幅度正确 |
| 视频帧所有权 | 采集与显示异步；输入尺寸、格式及交接协议 | 黑屏/红条排查；`tb_camera_store`和CDC仿真 | 缓冲正确不等于传感器曝光、外部时序或镜头已标定 |
| 显示与运动授权分离 | 语音短暂停顿；输入观测时间、质量及失声期限 | 900 ms间隙、1199/1200 ms边界和PS至PL回放 | 不能消除声源误判，长保持不等于真实连续发声 |
| 成套构建与独立启动 | bit/XSA/ELF/BOOT混用；输入版本清单及启动配置 | 产物哈希、FSBL初始化检查和历史启动记录 | 生成镜像与写入Flash、冷启动是不同验收阶段 |

先依据失败现象选择对应流程，将器件、路径和信号映射替换为本项目实际值，再执行最小验证。原始协作案例见[会话摘录](../report/collaboration_cases.md)，参数对照及原始输出见[优化验证](../report/optimization.md)。复用者应重新验证自身板卡和环境，不直接沿用原项目的阈值、引脚或结果。
